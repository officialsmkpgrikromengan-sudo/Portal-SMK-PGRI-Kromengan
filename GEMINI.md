# ATURAN UTAMA SISTEM & PENGEMBANGAN (STRICT DIRECTIVE)

> [!CRITICAL]
> **JANGAN MENAMBAH ATAU MEMBUAT FITUR ATAU FILE BARU KE DALAM WEB APP KECUALI DIMINTA EKSPLISIT OLEH PENGGUNA.**
> **DO NOT ADD OR CREATE NEW FEATURES OR NEW FILES IN THE WEB APP UNLESS EXPLICITLY REQUESTED BY THE USER.**

## Batasan Ruang Lingkup (Scope Discipline):
1. **Dilarang Menambah Fitur Baru**:
   - Hanya kerjakan, perbaiki, atau sesuaikan fitur yang diminta secara eksplisit oleh pengguna.
   - Jangan berinisiatif menambahkan menu, tombol, modul, rute, atau fungsionalitas tambahan yang tidak diminta.

2. **Dilarang Membuat File Baru**:
   - Jangan membuat file komponen baru, helper baru, file styling baru, atau modul baru di dalam aplikasi kecuali diperintahkan secara spesifik.
   - Gunakan dan optimalkan struktur file yang sudah ada.

3. **Prinsip Pengerjaan**:
   - Perintah pengguna adalah batas tertinggi lingkup kerja (*absolute ceiling*).
   - Fokus utama adalah perbaikan bug, keamanan, dan pemeliharaan kode yang diminta pengguna tanpa spekulasi.
